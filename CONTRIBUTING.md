# Contributing

Casualties Together is a co-op mod. Fixes and small features are welcome. You do not need a perfect implementation, or a full design doc, just to make a PR.

If the change is big, or you are not sure it is wanted, say so in the [Casualties Together discord](https://discord.gg/SA6H7mA6De) and ping Creature.

## A change
- If you use AI, say so. If we think you're using undisclosed AI, your change may be rejected on principle.
- One problem per pull request when you can. Two unrelated fixes are harder to read than two small requests.
- Comment your code. Don't make us spend an hour reading one small fix.
- Leave the rest of the file alone. A drive-by reformat makes the real change impossible to see.
- Play it if you can. Compiling is not the same as a host and a client actually doing the thing.
- Say which side you tried. A lot of bugs only show up for the person who is not the host, and vice versa.


## Pull request

Put this in the pull request description. If you already opened it, a comment with the same headings is fine. Blank sections are ok. "I don't know" is a fine answer.

```
### What
One or two sentences. What does a player see that they did not see before.

### Why
The bug, the annoyance, or any reasoning you have for making the change you did. Even just "I think this feature would be cool" is fine, as long as we know.

### Tried (mainly for bug fixing, so we can replicate it if needed)
- Game: demo or full, and the version if you know it
- Played as: host, client, or both
- What I actually did in game:

```
